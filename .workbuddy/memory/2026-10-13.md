## 技术经验（重要）

### MD → HTML 转换脚本（首次建立，建议长期沿用）
本期浏览器环境仍无现成转换脚本，**改为写 Python 转换器**，避免手工分段 Write 150KB+ HTML：
- 脚本：`C:\temp\md2html.py`（可复制进项目 `tools/` 目录长期使用）
- 逻辑：逐行解析 MD → 输出固定模板 HTML（CSS 与 DOM 完全照 `briefings/2026-10-07/*.html`）
  - `# 标题` → `<h1>`；`## 目录` → `<h2 id="toc">` + 嵌套 `<ul>`（锚点 `#1-xxx` → `#s1`、`#31-xxx` → `#s31`）
  - `## N. xxx` → `<h2 id="sN">` + `<p class="retlink">`（并吞掉紧跟的 `[【返回目录】](#目录)` 行）
  - `### 3.N / 4.N` → `<h3 id="s3N|s4N">`
  - `|` 表格 → `<table>`（`方向` 列首列按 利空/偏空→green、利多/偏多→red、中性→orange 加 class）
  - `> ...` → `<blockquote>`（多段用 `<p>` 包裹；`**本周关注**` 开头加 `class="warn"`）
  - `- 【标签】 **摘要**` + 后续 `└ **字段**：` → `<div class="event up|on|dn">`（class 按方向硬编码：3.1 on / 3.2 on / 3.3 dn / 3.4 up / 3.5 dn）
  - `1. ` → `<ol>`；`- `（非事件）→ `<ul>`；`**宏观面判断**：短期【x】· 中期【y】` → `.verdict bearish|bullish|neutral`
  - 末尾 `*数据来源：...*` → `<p class="dsrc"><em>...</em></p>`
- **必须处理的坑：字数配对**。MD 中 15 行存在**奇数个 `**`**（多为行尾多一个游离 `**`），简单 `re.sub(r'\*\*(.+?)\*\*')` 会在 HTML 里留下字面 `**`。修法：`normalize_bold()` —— 若 `**` 数为奇数，行尾为空则删行尾那个、否则删行首那个。
- 生成后**必须自检**：`html.count('**')==0`、`<strong>` 开闭数相等、`<u>`/`</u>` 配对、未转义 `&` 数为 0（`S&P` → `S&amp;P`）。
- 本期自检结果：`leftover_markers=0`、`strong_open=strong_close=730`、`u_open=u_close=5`、`raw_amp=0`。
