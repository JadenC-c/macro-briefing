# 宏观分析项目 —— 长期备忘

## 格式纪律（2026-10-14 起生效）

**`prompts/format-baseline.md` 是日报格式与篇幅的唯一权威数值来源**，以 `briefings/2026-07-23/` 为黄金样本。其余规范文件（`CLAUDE.md`、`prompts/daily-briefing.md`、`prompts/daily-briefing-html-template.md`）与之冲突时以基线为准。

### 硬指标（不可突破）

| 项目 | 上限 |
|---|---|
| MD 源文件 | 45 KB（> 50 KB 直接失败） |
| 正文总字数 | 14,000 字 |
| PDF 页数 | 12 页 |
| 一级章节 / 二级子章节 | 恰好 6 个 / 仅 4.1、4.2、4.3 |
| 表一 今日宏观数据 | 10 行 |
| 表二 近期宏观数据 | 18 行 |
| 任何表格单元格 | **120 字**（硬底线） |
| 表二「实际值」栏 | 20 字，**只放数值，不写叙述/引文/解读** |
| 表二「解读」栏 | 60 字，一句话 |
| 宏观事件跟踪 | 3–6 个；标题行 70 字；单卡片 1,300 字；章节 6,500 字 |
| 板块 4 关键因素 | 每板块 4–6 条，单条 450 字 |
| 板块 5 / 板块 6 | 4–5 条（≤300 字）/ 6–8 条（≤180 字） |

### 四条硬性禁止

1. 禁止在「3. 宏观事件跟踪」下新增 `### 3.x` 子标题（该章保持平铺列表）。
2. 禁止在表格单元格内抄录原文引用。
3. 禁止表格出现"（回顾）"类历史复述行。
4. 禁止写入对 10 个品种无 3 跳以内传导链的事件。

### 事件寿命机制

连续 **2 期无实质新进展**即移出当期（保留历史）；已消退移出；单期 > 6 个则合并；单期新增 ≤ 2 个。
"实质新进展"= 出现新的可量化变化（价格、数量、政策动作、时限），仅有媒体报道/机构评论不算。

### 写作方法：两遍法 + 强制删减

第一遍只写事实（不写解读）→ 第二遍只写解读（每格一句话）→ 第三遍按校验结果强制删减。
删减优先顺序：①无传导链的日历行 ②历史复述行 ③重复口径 ④同一判断的第二次表述 ⑤标题与事件字段的重复 ⑥修饰性词汇。

### 交付流程（强制）

1. 写 MD
2. `verify-briefing.ps1 -Date YYYY-MM-DD` → **必须全 PASS**
3. `scripts/md2html.py -Date YYYY-MM-DD` 生成 HTML（不手写 HTML）
4. `export-pdf.ps1 -Date YYYY-MM-DD` 生成 PDF
5. 复制 HTML 覆盖 `index.html`
6. git add / commit / push

### 冲突定案（历史上写法不一致处，此处定死）

- 「宏观面判断」写法固定为 **`短期【偏X】· 中期【偏X】`**（带【】，HTML badge 与转换器正则依赖它）。
- 事件标签主用【升级】（红）/【持续】（橙）/【缓和】（绿）；扩展【转折】=红、【新增】=橙。
- 数据来源行：MD `*数据来源：…*`，HTML `<p class="dsrc"><em>…</em></p>`。

## 工具踩坑（长期有效）

- 含中文的 `.ps1` **必须存为 UTF-8 带 BOM**，否则 PowerShell 5.1 按 GBK 解析导致中文字符串失效。重复 BOM 会让首行 `param` 报错。
- PowerShell 5.1 中 `@()` 无 `.Add()`（报"集合的大小是固定的"），累积列表用 `New-Object System.Collections.ArrayList` 或 `+=`。
- 脚本内**不要用 `exit`**：通过 `&` 调用会连带结束宿主会话。改用 `$global:LASTEXITCODE` + 可选 `-StrictExit`。
- Python 输出中文到 PowerShell 前需 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`。
- Git 推送长期受网络阻断（`Recv failure: Connection was reset`）；本地提交正常，网络恢复后 `"D:\Git\cmd\git.exe" push origin main` 即可。

## 项目既定约定

- 中国交易习惯：**利空=绿、利多=红、中性=橙**（红涨绿跌）。
- **禁止 emoji 与颜文字**（含 `⚠️`）——10-13 曾违规，校验器会拦截。
- 页脚只放页码；数据来源放正文末尾；不写"仅供参考/不构成投资建议"类免责声明。
- 追踪品种 10 个：玻璃 FG / 纯碱 SA / 螺纹 RB / 热卷 HC / 铁矿 I / 焦炭 J / 焦煤 JM / 铜 CU / 铝 AL / 锌 ZN。
