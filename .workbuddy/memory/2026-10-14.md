### 5. 工具使用要点（踩坑记录）

- `verify-briefing.ps1` 与 `scripts/md2html.py` 含中文，**.ps1 必须存为 UTF-8 带 BOM**，否则 PS 5.1 按 GBK 解析导致中文字符串失效。
- PowerShell 5.1 中**数组 `@()` 没有 `.Add()` 方法**（会抛"集合的大小是固定的"），累积列表要用 `New-Object System.Collections.ArrayList` 或 `+=`。
- 脚本内**不要用 `exit`**——通过 `&` 调用时会连带结束宿主会话。已改为设置 `$global:LASTEXITCODE`，自动化场景加 `-StrictExit`。
- Python 输出中文到 PowerShell 需先 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`，脚本内也做了 `sys.stdout.reconfigure(encoding='utf-8')`。
