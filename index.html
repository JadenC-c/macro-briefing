3. 宏观事件跟踪

【返回目录】

持续追踪影响品种的宏观事件，每日更新最新进展。
持续 美国CPI与美联储加息路径

事件：美联储9月已将政策利率上调至3.75%—4.00%，市场在“10月暂停、12月再加息”和更快收紧之间反复交易。

最新（10月14日）：美国9月CPI将于北京时间20:30公布，市场预期同比由3.4%升至3.6%，环比升至0.6%；核心CPI环比预期由0.3%降至0.2%。隔夜10年期美债收益率约5.21%，美元指数约102.20。

现状：若核心CPI高于0.2%且整体同比达到或超过3.7%，12月加息定价可能进一步上升；若核心明显回落，市场可能把整体通胀归因于能源冲击。

影响品种：铜、铝、锌、铁矿石 → 美债收益率和美元上行会压制估值；核心通胀回落则利多风险资产。
升级 中东冲突与石油运输风险

事件：霍尔木兹海峡通行受限、胡塞武装持续袭击沙特目标，原油供应和航运成本长期处于高风险状态。

最新（10月14日）：利雅得再传爆炸声，沙特能源部确认阿美公司一处行政建筑遭袭后发生有限火灾；隔夜布油收于105.69美元/桶、WTI收于94.14美元/桶。OPEC月报同时将2026年需求增量预测由38万桶/日下调至18万桶/日，并显示9月OPEC+产量明显回升。

现状：地缘供应风险仍高，但产量修复和需求预期下调限制油价单边上行，油价更可能维持高波动而非顺畅趋势。

影响品种：玻璃、纯碱、黑色、有色 → 能源与运输成本抬升形成成本支撑；若冲突缓和或供应恢复，成本溢价会快速回吐。
升级 智利大型铜矿劳资冲突

事件：Centinela铜矿709名工人自10月7日起罢工，Escondida主管工会与BHP的强制调解未能达成协议。

最新（10月14日）：Escondida约1,020名主管及员工计划于智利当地时间8:00、北京时间19:00启动罢工；Centinela罢工进入第二周，若延续至11月，工会称当月产量可能减少一半。

现状：供应风险已从预期阶段进入执行窗口，但铜价能否持续上行仍取决于罢工持续时间和美国CPI后的美元方向。

影响品种：铜 → 矿端供应收紧利多；铝、锌 → 有色风险偏好可能被带动，但跟涨力度弱于铜。
持续 中国“上游通胀、终端偏弱”剪刀差

事件：能源和原材料价格上涨推动PPI快速回升，但房地产和居民消费恢复仍慢，产业链利润继续向上游集中。

最新（10月14日）：9月PPI同比5.0%、环比1.2%，均显著走高；CPI同比仅0.9%、低于1.0%的预期，居住价格同比下降0.3%。

现状：这不是全面需求繁荣，而是输入性成本、供给约束与出口韧性的组合。中下游能否提价将决定利润和开工率。

影响品种：玻璃、纯碱、螺纹、热卷 → 成本有支撑但终端承接不足，价格反弹空间受限；煤焦、有色 → 更直接受益于上游涨价。
持续 外贸高增与贸易摩擦风险

事件：中国出口保持高增，同时美国对华海事301港口费暂停期将于11月9日到期，多国对“产能过剩”的政策压力仍在。

最新（10月14日）：9月出口同比36.3%，钢材出口1,049.2万吨；1—9月贸易顺差达到9,380亿美元。强出口缓冲内需走弱，但顺差扩大也会提高关税、配额和港口费措施升级的概率。

现状：短期是需求利多，中期是政策风险；需观察钢铁、铝材、新能源产品是否出现新的限制措施。

影响品种：热卷、铝、铜 → 出口和制造业需求偏多；铁矿石、煤炭 → 港口费与航运成本可能推高到岸成本。

4. 品种宏观影响分析

4.1 建材板块

宏观面判断： 短期 中性偏空 · 中期 中性

  1. 居民端价格仍弱 —— CPI同比0.9%低于预期，居住价格同比下降0.3%，说明地产和居民需求尚未形成明显改善。对玻璃来说，竣工与装修需求仍缺乏新的强验证。
  2. PPI抬升带来成本支撑 —— 油气、煤炭和化工价格上涨有利于抬高玻璃、纯碱成本中枢，但如果终端不能顺利提价，生产利润会先被压缩，难直接转化为持续上涨。
  3. 外贸强但传导有限 —— 出口和进口双双超预期有利于制造业信心，却无法直接替代房地产需求。建材仍需等待10月19日地产、投资和三季度GDP数据确认。
  4. 能源成本双向波动 —— 中东袭击支撑油价，但OPEC产量修复和需求下调限制上方空间。能源成本只能托底建材成本，不能替代终端需求。

盘面：截至15:00，玻璃主力856元/吨，较前结算跌0.35%；纯碱主力944元/吨，跌3.18%（来源：AkShare/Sina期货）。纯碱跌幅更大，显示高库存与弱需求仍主导盘面。

本周关注：美国CPI引发的油价、美元变化，以及10月19日中国房地产投资、新开工、竣工和销售数据。

4.2 黑色板块

宏观面判断： 短期 偏空 · 中期 中性偏空

  1. 钢材出口是主要支撑 —— 9月钢材出口1,049.2万吨、环比增长3.3%，连续第五个月超过1,000万吨，对热卷和钢材去库有帮助。若外贸限制没有升级，出口仍能缓冲国内需求弱势。
  2. 矿石供应继续增加 —— 9月铁矿石进口10,981.7万吨，1—9月累计同比增长4.1%；在钢厂盈利率低、铁水仍有减量预期的环境中，矿价上方压力更明确。
  3. 煤焦成本与复产博弈 —— PPI中煤炭行业同比涨幅扩大，说明现货成本并未完全坍塌；但焦炭提降和矿山复产仍压制双焦。钢厂利润若修复后迅速复产，可能先利多原料、后压制成材。
  4. 美国CPI影响风险偏好 —— 超预期通胀会推高美元和长端利率，铁矿及黑色估值承压；若核心CPI回落，短线超跌反弹概率上升。

盘面：截至15:00，螺纹钢3073元/吨（-0.39%）、热卷3237元/吨（-0.52%）、铁矿石674元/吨（-0.81%）、焦炭2000元/吨（-1.60%）、焦煤1536.5元/吨（-1.54%）（来源：AkShare/Sina期货）。原料端跌幅大于成材，市场仍在交易负反馈和供应恢复。

本周关注：铁矿港口库存与铁水产量、焦炭第三轮提降、钢材去库速度；热卷需额外观察出口政策变化。

4.3 有色板块

宏观面判断： 短期 中性 · 中期 中性偏多

  1. 铜矿供应扰动升级 —— Centinela罢工进入第二周，Escondida罢工计划于北京时间19:00启动。若两处扰动持续，铜精矿紧张会进一步加剧，对铜价构成最直接支撑。
  2. 国内贸易和PPI数据偏强 —— 进口同比31.0%、PPI同比5.0%均超预期，说明生产和补库需求仍有韧性；这对铜、铝、锌的国内需求预期偏多。
  3. 高利率仍限制估值 —— 10年期美债收益率约5.21%，晚间美国CPI若偏热，美元和实际利率可能重新走高，足以抵消部分矿端利多。
  4. AI需求预期出现分歧 —— IMF认为AI投资支撑全球增长，但同时警告估值和融资风险；隔夜AI概念走弱已拖累伦铜，铜价需要产业端供应收紧来抵消宏观波动。

盘面：隔夜LME铜14,578美元/吨（-0.3%）、铝3,039美元/吨（-0.4%）、锌3,731.5美元/吨（-0.7%）；截至国内15:00，沪铜111,080元/吨（+0.16%）、沪铝23,285元/吨（-0.75%）、沪锌25,665元/吨（-0.89%）（来源：新浪财经、AkShare/Sina期货）。铜因罢工预期相对抗跌，铝锌仍受宏观和高估值压力。

本周关注：Escondida是否实质停产、Centinela调解结果、美国CPI后美元和10年期美债收益率方向。

5. 今日宏观交易主题

【返回目录】

国内“外贸强、上游价格强、终端价格弱”与海外“高通胀、高利率”同时存在，晚间美国CPI和智利铜矿罢工将决定风险偏好与有色供应溢价谁占上风。

今日重点关注：

  • 20:30美国CPI：先看核心、再看整体
    整体CPI受能源影响较大，真正决定美联储路径的是核心CPI。若核心环比不高于0.2%，即使整体同比升至3.6%，商品也可能在最初波动后修复；若核心达到0.3%或更高，美元与美债收益率上行将压制有色和黑色。
  • 19:00 Escondida罢工窗口
    铜的供给利多与美国CPI仅相隔一个半小时。罢工正式启动但规模有限时，铜价可能冲高回落；只有影响生产并持续数日，供应溢价才更牢固。
  • 国内数据不是“全面复苏”
    出口、进口和PPI都强，但CPI仍低于预期。交易上应把强数据更多映射到热卷、铜和上游原料，而不是直接外推为玻璃、螺纹的地产需求反转。
  • 油价高波动继续影响成本线
    中东袭击升级支持油价，OPEC产量修复和需求下调又构成压制。对玻璃、纯碱和黑色而言，成本支撑存在，但不宜把成本上涨等同于终端价格必涨。

6. 宏观风险提示

【返回目录】

  • 美国通胀超预期：若核心CPI高于0.2%，美债收益率与美元可能上行，压制有色和铁矿石估值。
  • 通胀结构错位：若整体CPI高、核心CPI低，盘面可能先跌后涨，晚间追单风险较高。
  • 铜矿罢工反转：Escondida若快速达成协议，供应溢价可能回吐；若与Centinela长期停产，铜价弹性放大。
  • 中东供应冲击：若袭击波及石油设施或运输通道，油价与海运费可能跳升，国内输入性成本上行。
  • 贸易摩擦升级：出口高增和顺差扩大可能触发关税、配额或港口费措施，热卷、铝材需防政策反转。
  • 铁矿供应累积：进口继续增加而钢厂利润偏低，矿价反弹可能受港口库存约束。
  • PPI与CPI剪刀差：若中下游无法提价，玻璃、纯碱和钢材企业可能减产或降价，盘面波动放大。
